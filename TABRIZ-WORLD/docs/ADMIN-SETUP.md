# راه‌اندازی مدیر TABRIZ WORLD

پنل مدیریت در مسیر `prototype/admin-dashboard.html` قرار دارد. این پنل با Supabase Auth وارد می‌شود و فقط حساب‌هایی که در جدول `public.tw_admins` ثبت شده‌اند می‌توانند محصولات را ببینند و تأیید یا رد کنند.

## ۱. ساخت حساب مدیر

ابتدا از صفحه پنل فروشنده یک حساب با ایمیل خود بسازید:

`prototype/seller-dashboard.html`

اگر تأیید ایمیل Supabase فعال باشد، لینک تأیید را از ایمیل باز کنید. رمز عبور را در اختیار هیچ‌کس قرار ندهید.

## ۲. اعطای دسترسی مدیر

در Supabase Dashboard همان پروژه، وارد SQL Editor شوید و دستور زیر را اجرا کنید. مقدار ایمیل را با ایمیل دقیق همان حسابی که ساخته‌اید جایگزین کنید:

```sql
insert into public.tw_admins (user_id)
select id
from auth.users
where lower(email) = lower('YOUR_ADMIN_EMAIL')
on conflict (user_id) do nothing;
```

اگر حساب هنوز ساخته یا تأیید نشده باشد، هیچ ردیفی اضافه نمی‌شود. پس از ساخت/تأیید حساب، دستور را دوباره اجرا کنید.

برای بررسی دسترسی:

```sql
select u.email, a.user_id, a.created_at
from public.tw_admins a
join auth.users u on u.id = a.user_id;
```

برای لغو دسترسی یک مدیر:

```sql
delete from public.tw_admins
where user_id = (
  select id from auth.users
  where lower(email) = lower('YOUR_ADMIN_EMAIL')
);
```

## ۳. ورود به پنل مدیریت

صفحه `prototype/admin-dashboard.html` را باز کنید و با همان ایمیل و رمز عبور وارد شوید.

- محصولات جدید در وضعیت «در انتظار بررسی» قرار می‌گیرند.
- با «تأیید و انتشار»، محصول برای بازدیدکنندگان فروشگاه سه‌بعدی قابل مشاهده می‌شود.
- با «رد محصول»، کالا از فهرست عمومی خارج می‌ماند.
- دسترسی مدیر از جدول محافظت‌شده `tw_admins` و سیاست‌های RLS بررسی می‌شود؛ هیچ کلید service-role در مرورگر قرار نگرفته است.

## نکات امنیتی

- فقط مدیر اصلی باید دستور اعطای دسترسی را در SQL Editor اجرا کند.
- هرگز کلید service-role یا رمز حساب را در فایل‌های GitHub یا کد مرورگر قرار ندهید.
- تصاویر در bucket عمومی هستند تا عکس کالاهای تأییدشده در فروشگاه قابل نمایش باشد؛ بنابراین هر کسی که نشانی تصویر را داشته باشد می‌تواند آن تصویر را ببیند.
- این پنل فعلاً فقط مدیریت وضعیت محصولات را انجام می‌دهد؛ تأیید هویت فروشنده، مدیریت سفارش‌ها، بازپرداخت و پرداخت بانکی هنوز در این مرحله پیاده‌سازی نشده‌اند.
