# Savash — Buyer Overview

## Short description
Savash is a mobile-friendly, top-down squad-combat game. The player leads a five-soldier squad through a 30-wave campaign, fights increasingly difficult enemy groups, and faces boss encounters every fifth wave.

## Editions
- **Buyer demo:** first 3 waves only, distributed as a separate Android demo APK for private evaluation.
- **Full edition:** all 30 campaign waves, including six boss encounters on waves 5, 10, 15, 20, 25 and 30.
- The demo uses the separate Android application ID `com.savash.demo`; the full edition uses `com.savash.game`.

## Included gameplay
- 30 campaign waves in the full edition.
- Boss encounters on waves 5, 10, 15, 20, 25 and 30.
- Five-soldier squad with automatic support fire.
- Touch movement controls plus keyboard controls.
- Hold-to-fire combat, pause/resume, and a main menu.
- Built-in soundtrack, music toggle, volume control, and optional user-selected audio.

## Technical delivery
- Android application ID: `com.savash.game` (full edition).
- HTML/JavaScript game source and local media assets.
- Capacitor 7 Android wrapper.
- GitHub Actions workflows for full Android APK builds, private-review 3-wave demo builds, and source handover ZIP.
- Main source repository is intended to remain private during marketing and buyer evaluation.
- Source archive excludes the separate `TABRIZ-WORLD` project.
